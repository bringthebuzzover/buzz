# Pricing & business models

Brainstorm + parallel research (2026-08-11). **Not committed behavior. Not
legal advice.** Promoting any SKU needs an explicit PRODUCT / pricing decision.

Related: [`markets.md`](markets.md) (Upfront, CPE collars, prepaid credits,

## Thesis

Buzz is ops-mediated today (brand PLS, org PLG, attributed IG). The scarce
asset is **cleared, graded campus attention + fulfillment trust** — not a clean
“influencer media budget” to take 15% of.

**Doctrine (cross-lens agreement):**

1. **Bill brands; bless orgs.** Never tax Apply / verification.
2. Attach fees to **cleared seats / drops / seasons**, not vague campaign %.
3. Remedies in **inventory / credits** first; cash CPE last and capped.
4. Org skin via **holdbacks / grades**; shared upside pools over “Buzz tax.”
5. **Customer float** (prepaid) before investor-yield products.
6. **Semester clock** beats SaaS monthly theater while drops are ops-heavy.

## Verdict (next 12 months)

**Primary SKU:** semester **Campus Access Retainer** + **Drop Activation / Seed
fee** + **Seat Clear Fee** (per accepted + shipped + ≥1 Buzz-linked post).

**Org side:** Apply free forever; package ≈ product/perk + status; soft
holdback as reliability grade / perk unlock (cash holdback later). Org payouts
**gross** — Buzz fee stays on the brand invoice.

**Adjacent bets:** fulfillment/sample margin; one agency white-label desk.

**Explicitly deprioritize:** pure seat SaaS as hero SKU; org application fees;
cash CPE guarantees; auctions on named student orgs; DIY notes/tokens (see
markets.md).

## Opinionated sequence

```
Retainer + Seed/Seat Clear + free Apply + soft grades
  → escrow + prepaid credits + season fences + RFQ
    → Campus Upfront + category windows + process SLAs
      → CAB ARR + soft-CPE meter (funds collar reserves)
        → rare peak auctions / reverse exchange
          ✗ org Apply taxes
          ✗ cash CPE hero SKU
          ✗ notes / tokens / student PII lead-gen
```

## Kill criteria

- No durable **Cleared** definition → invoice wars.
- Visible fees collapse Apply or Accept→Post.
- Brands only accept **cash CPE refunds** as remedy.
- Two seasons show **no calendar premium** → yield products are theater.
- Measurement disputes exceed fee revenue.
- “Extracting from students” narrative sticks and co-op framing can’t fix it.
- Growth subsidies never reach positive campus-cohort unit economics.
